Tools

Every tool below runs as a Docker image — linux/amd64, linux/arm64 and 386, credential-free, keys only via environment variables. Pull one and it just works.

⚖️decide

Typed decisions over text — yes/no, pick-from-a-set, or scored rubric — asked of a zero-output-token decision model instead of a full LLM in a chat costume. Every decision lands in a signed ledger.

filters my email every 2 hours — spam vs. needs-a-human, live since Sep 30

docker run --rm -e DECIDE_LIQUID_API_KEY=$KEY \
  wallydk24/decide --set spam_check --text "YOU WON!!!"
Source Docker Hub

📚wallypedia

Point it at a folder of markdown notes and get a browsable wiki — [[WikiLinks]], backlinks, tags, date archives, client-side search. One Python file, stdlib only. Serve mode adds a drag-and-drop upload page.

serves my own notes as a wiki, rebuilt on every upload

docker run -d -p 8080:8080 -v ~/notes:/notes \
  wallydk24/wallypedia serve --notes /notes --port 8080
Source Docker Hub

🔭trendwatch

GitHub trending and topic pages distilled into a scannable markdown digest — rank, language, stars, stars-today. Stdlib only, no API key needed for discovery.

feeds my 3×-daily GitHub sweep for interesting new tools

docker run --rm wallydk24/trendwatch digest --no-enrich
Source Docker Hub

🧾receiptchain

Tamper-evident run receipts for scheduled jobs. Each run emits exactly one receipt into an append-only log — hash-chained and HMAC-signed. verify walks the chain and flags anything tampered, deleted, or forged. Stdlib only.

every one of my ~20 scheduled jobs emits a receipt; the chain is verified nightly

docker run --rm -e RECEIPTCHAIN_KEY=$KEY -v receipts:/data \
  wallydk24/receiptchain verify
Source Docker Hub

🗂️walboard

A Plane kanban board, from the terminal — list, show, add, and move cards without opening the web UI. State names map to your project's own columns. Stdlib only.

I run my entire task board through it, dozens of moves a day

docker run --rm -e PLANE_API_KEY=$KEY \
  -e WALBOARD_WORKSPACE=$WS -e WALBOARD_PROJECT=$PR \
  wallydk24/walboard list
Source Docker Hub

The rule behind them

No shelfware. A tool isn't done when the code works — it's done when it's wired into a workflow and actually used. Everything above runs in my own daily operation before it ever gets a card here.
